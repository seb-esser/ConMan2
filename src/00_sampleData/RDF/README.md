# RDF sample data

`lbd_office/office_v1.ttl` … `office_v4.ttl`: a synthetic Linked-Building-Data office (Building
Topology Ontology BOT plus a small `ex:` vocabulary), with controlled changes per version
(`CHANGELOG.json`). Generated by `tools/make_lbd_office_series.py`; no licence restrictions.

Every file mixes an **inline TBox** (ontology header with `owl:imports`, class and property
declarations, an OWL restriction) with the **ABox**. This exercises the TBox/ABox partitioning:

- With `rdf_tbox = exclude` (the default), only the ABox is versioned. v1 → v2 also changes the TBox
  (`owl:versionInfo`, new class `ex:MeetingRoom`). That change shows up solely as a new TBox
  fingerprint on the dataset node.
- The data covers literals with datatypes and language tags, PROPS-style blank-node properties, an
  `rdf:List`, a root blank node, multi-valued predicates, a re-targeted relation (v3: a desk moves to
  another space), and an IRI rename (v4).

Project id: derived from the `owl:Ontology` IRI as the filename-safe slug
`example.org_tum_office-building`.
